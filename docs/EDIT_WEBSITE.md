# Edit the AsV_IDE website yourself

You only need to edit one file: [`site-settings.json`](https://github.com/mistfans24-maker/AsV_IDE/edit/main/docs/site-settings.json).

1. Open the link above while signed in to GitHub.
2. Change the words or links inside the quotation marks.
3. Press **Commit changes** at the bottom of GitHub.
4. Wait about 1–3 minutes, then refresh [the public site](https://mistfans24-maker.github.io/AsV_IDE/).

## What each setting changes

- `heroKicker`, `heroTitle`, `heroDescription`: text at the top of the homepage.
- `motionWords`: the large animated words. Keep the square brackets, commas, and quotation marks.
- `founderName`, `founderRole`, `founderBio`: the team card.
- `discordUrl`: your full Discord invite, such as `https://discord.gg/example`. Leave it blank to hide Discord buttons everywhere on the public site.
- `supportEmail`: an email address for the support panel. Leave blank to hide Email us.
- `buyMeACoffeeUrl`: your full Buy Me a Coffee link. Leave blank to keep the “coming soon” label.

Do not paste passwords, API keys, OAuth secrets, or private tokens into this file. It is public.

For live release controls such as maintenance lock and download availability, use the [admin dashboard](https://mistfans24-maker.github.io/AsV_IDE/admin/). Those controls require the admin login and are not stored in this public file.
